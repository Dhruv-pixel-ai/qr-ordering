⚙️ First-time setup — QZ Tray

Do this once on the counter PC. Takes about 5 minutes.

  1. Download and install QZ Tray (free) from qz.io/download. It runs silently in the background.
  2. After install, a QZ Tray icon appears in the Windows system tray (bottom-right). It starts automatically with Windows.
  3. Add the KD'S CAFE certificate to QZ Tray: right-click the QZ Tray icon → Site Manager → click + → browse to the kds-cafe-qz.crt file you downloaded (link below) → click OK → Save.
  4. Come back to this page and click Retry above. The status bar should turn green.
  5. Enter your kitchen printer's IP address, select the counter printer from the dropdown, click Test Print on each to confirm, then Save Printer Settings.
  6. From now on: clicking Print on an order sends the KOT silently to the kitchen. Clicking Generate Bill sends the bill silently to the counter. No dialog, no clicking.
